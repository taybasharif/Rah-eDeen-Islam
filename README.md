## 🕌 ۳. اوقاتِ نماز کی تکنیکی خصوصیات (Prayer Times Engine)

1. **تمام ۱۰ فرض، سنن اور نوافل کے اوقات:**
   - **تہجد (صلاة التهجد):** رات کی آخری تہائی کا درست فلکیاتی حساب۔
   - **فجر (الفجر):** صبح صادق (۱۸ ڈگری زاویہ)۔
   - **طلوعِ آفتاب (الشروق):** سورج کا افق سے نکلنا۔
   - **اشراق (صلاة الإشراق):** طلوع کے ۱۵ منٹ بعد (ممنوعہ وقت کے خاتمے پر)۔
   - **چاشت (صلاة الضحىٰ):** دن چڑھے تا قبلِ زوال۔
   - **ظہر (الظهر):** زوالِ آفتاب کے فوراً بعد۔
   - **عصر (العصر):** مثلین (فقہ حنفی ڈیفالٹ) مع مثلِ اول شافعی آپشن۔
   - **مغرب (المغرب):** غروبِ آفتاب۔
   - **اوابین (صلاة الأوابين):** مغرب کے بعد کے نوافل۔
   - **عشاء (العشاء):** شفقِ احمر کے اختتام پر (۱۸ ڈگری زاویہ)۔
2. **۱۲ گھنٹے کا معیاری فارمیٹ (12-Hour AM/PM):**
   ہر وقت واضح طور پر مثلاً `4:00 PM`، `5:38 PM`، `11:56 AM` میں نظر آتا ہے۔
3. **پاکستان کے ۲۰ اہم شہر:**
   وہاڑی، لاہور، اسلام آباد، راولپنڈی، کراچی، ملتان، فیصل آباد، پشاور، کوئٹہ، سیالکوٹ، گوجرانوالہ، بہاولپور، سرگودھا، ساہیوال، ڈیرہ غازی خان، حیدرآباد، سکھر، ایبٹ آباد، مظفر آباد، گلگت۔
4. **خودکار مڈ نائٹ تاریخ ریفریش (Asia/Karachi PKT):**
   بیک گراؤنڈ ڈیمن پاکستان وقت کے مطابق رات ۱۲ بجے تاریخ بدلتے ہی بغیر پیج ریلوڈ کیے اگلے دن کے اوقات خودکار لوڈ کرتا ہے۔

## 🚀 ۴. گٹ ہب پر اپ لوڈ کرنے کا طریقہ (How to Upload to GitHub)

### مرحلہ ۱: گٹ ہب پر نئی ریپوزیٹری بنائیں
1. اپنے براؤزر میں [https://github.com](https://github.com) کھولیں اور لاگ ان کریں۔
2. اوپر دائیں جانب **+** کے نشان پر کلک کر کے **New repository** منتخب کریں۔
3. ریپوزیٹری کا نام درج کریں، مثلاً: `rah-e-deen-islam`
4. اسے **Public** رکھیں اور **Create repository** پر کلک کریں۔

### مرحلہ ۲: اپنے کمپیوٹر سے کوڈ پش کریں
اپنے لیپ ٹاپ پر ٹرمینل یا PowerShell کھولیں اور پروجیکٹ فولڈر میں جا کر یہ کمانڈز چلائیں:

```bash
cd "C:\Users\HP\Desktop\Rah-e-Deen-Islam"

# اگر گٹ پہلی بار شروع کر رہے ہیں:
git init
git add .
git commit -m "feat: complete production-ready Rah-e-Deen-Islam website for GitHub and Vercel"

# اپنی برانچ کو main بنائیں:
git branch -M main

# اپنی گٹ ہب ریپوزیٹری کا ریموٹ لنک جوڑیں (اپنا یوزر نیم لگائیں):
git remote add origin https://github.com/YOUR_USERNAME/rah-e-deen-islam.git

# کوڈ گٹ ہب پر اپ لوڈ کریں:
git push -u origin main
```

## ⚡ ۵. ورسل پر لائیو ڈپلائی کرنے کا طریقہ (Deploying Live on Vercel)

### طریقہ (صرف ۲ منٹ کا کام):
1. [https://vercel.com](https://vercel.com) پر جائیں اور اپنے **GitHub** اکاؤنٹ سے لاگ ان (Sign In) کریں۔
2. ڈیش بورڈ پر **Add New...** بٹن دبا کر **Project** پر کلک کریں۔
3. آپ کی گٹ ہب ریپوزیٹریز کی فہرست میں سے `rah-e-deen-islam` نظر آئے گی، اس کے سامنے **Import** پر کلک کریں۔
4. سیٹنگز میں کچھ بھی تبدیل کرنے کی ضرورت نہیں ہے (کیونکہ `vercel.json` فائل پروجیکٹ میں پہلے سے موجود ہے اور یہ ایک اسٹیٹک ویب سائٹ ہے)۔
5. نیچے نیلے رنگ کے **Deploy** بٹن پر کلک کریں۔
6. تقریباً ۳۰ سیکنڈ میں ورسل آپ کی ویب سائٹ کو لائیو کر دے گا اور آپ کو ایک فری محفوظ HTTPS لنک فراہم کر دے گا، جیسے:  
   👉 `https://rah-e-deen-islam.vercel.app/`

### کسٹم ڈومین جوڑنا (Custom Domain Setup):
اگر آپ کا اپنا ڈومین ہو (مثلاً `rahedeen.com` یا `rahedeenislam.pk`):
1. ورسل پروجیکٹ کی **Settings → Domains** میں جائیں۔
2. اپنا خریدا ہوا ڈومین لکھ کر **Add** کریں۔
3. ورسل آپ کو DNS ریکارڈز (CNAME اور A Record) بتائے گا، وہ اپنے ڈومین پرووائیڈر (GoDaddy, Namecheap وغیرہ) کے پینل میں شامل کر دیں۔ چند منٹ میں آپ کا ڈومین لائیو ہو جائے گا۔
